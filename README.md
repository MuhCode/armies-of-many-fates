Armies of Many Fates is a Turn-Based RPG Roguelite produced in Godot. It will feature for now a demo with a core gameplay loop of Camp -> Shop -> Event -> Battle and
will repeat. The anticipated demo build or MVP release is aimed around May 2027 and will feature a traversable map with seeded routes and a DAG generating it, a 
profile system with sync'd achievements, and multiplayer mid-battle with a 3x3 grid allowing for 9 units battling at once in a simulated battle between armies on the 
field with the commander also getting a turn.
