Definition of Done (DoD):

- (Refer to Git Project) All items in backlog when created require a short description, relevant title, and 1-5 completion criteria bullet points 
- When those criteria are met the item can be marked for review
- The item must also be locally tested with the recent version on the main branch
- When complete a PR can be started
- All "Done" items require a PR and need to be reviewed by at least 1 other team member
- During the review ensure to again double check with the most recent build on the "main" branch
- If there are no errors, it runs, and the code is written efficiently from a normal view it can be merged to main and completed on the board
